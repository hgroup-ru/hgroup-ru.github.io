# Осознанные отклонения от upstream

Этот файл содержит только случаи, где RU намеренно не повторяет текст закреплённого upstream буквально. Они не дают разрешения свободно исправлять или переосмысливать официальный source.

При переходе на новую upstream revision каждый пункт необходимо проверить заново и удалить, если upstream уже исправлен/обновлён.

## Level 23 — Blaze Discard

В закреплённом upstream один шаг примера ошибочно переключает перспективу с Cathy на Alice, хотя речь продолжает идти о восприятии Cathy.

RU намеренно сохраняет Кэти как наблюдателя в этом шаге.

## Level 24 — Unnecessary Bad Chop Move Ejection with Trash Push Discharge

Example 3 называет Alice, Bob, Cathy и Donald, но текст upstream одновременно называет ситуацию `3-player game`.

RU намеренно использует формулировку «в игре на четверых».

## `how-to-join` — актуальный Discord microphone/PTT UI

Закреплённый upstream использует устаревший шаг `Output Device`. RU намеренно следует проверенному актуальному Discord flow:

`Input Device` / `Mic Test` / `Input Mode` -> `Push to Talk` -> `Edit Keybind`.

Это correction внешнего UI, а не изменение игровой семантики.
