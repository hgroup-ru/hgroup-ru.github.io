## Проблема

Закреплённая версия upstream использует устаревший шаг `Output Device` при настройке микрофона и Push to Talk в Discord.

Русская версия была обновлена под более новый интерфейс и использует последовательность `Input Device` / `Mic Test` / `Input Mode` → `Push to Talk` → `Edit Keybind`.

## Перед Pull Request

Discord — внешний сервис, поэтому эта карточка не является доказательством актуального интерфейса.

Непосредственно перед отправкой Pull Request нужно:

1. проверить текущий desktop-интерфейс Discord;
2. подтвердить реальные названия разделов и controls;
3. проверить последовательность действий от выбора микрофона до назначения Push to Talk;
4. сравнить её с текущей английской страницей upstream;
5. не копировать русскую инструкцию механически, если Discord снова изменил UI.

## Предлагаемое изменение

Если upstream-инструкция всё ещё устарела, минимально обновить английские шаги под текущий интерфейс Discord, сохранив цель исходной инструкции.

Это исправление внешней документации, а не изменение правил Hanabi.

## Scope и проверка

Ожидается правка только страницы `how-to-join`, если текущая структура upstream не требует другого.

После изменения:

- вручную пройти описанные шаги в актуальном Discord;
- проверить названия controls и порядок действий;
- выполнить formatter/lint, требуемые upstream.
