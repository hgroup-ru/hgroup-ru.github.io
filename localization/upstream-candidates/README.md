# Upstream-кандидаты

[`UPSTREAM_CANDIDATES.md`](../UPSTREAM_CANDIDATES.md) — короткий реестр. Здесь лежат подробные карточки.

Структура:

- [`product/`](product/) — переносимые продуктовые улучшения;
- [`diagrams/`](diagrams/) — локальные диаграммы/YML и их audit;
- [`content/`](content/) — исправления текста и внешних инструкций.

Карточка хранит только необходимое: статус, предложение, пользу, сложность переноса, текущую реализацию, проверку перед PR, способ переноса, QA и PR.

`transfer: low / medium / high` означает **техническую сложность переноса**, а не вероятность принятия upstream.

`candidate` не становится `ready`, пока находка не перепроверена по текущему upstream.
