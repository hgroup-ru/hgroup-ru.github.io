## 2026-08-17 — Whole-site consistency audit

### Изменено

- Пользовательские упоминания `Beginner’s Guide` приведены к «Руководству для начинающих» в основных точках входа, навигации и связанных материалах.
- `Challenge Questions` приведены к «Контрольным вопросам» в заголовках, навигации и обычной пользовательской прозе.
- Локализованы пользовательские названия Official Challenge Questions для уровней 5–8; формальные названия H-Group conventions внутри них сохранены там, где это требуется терминологией.
- Регистр `Chop/chop` унифицирован по контексту: самостоятельные UI-подписи и заголовки используют `Chop`, обычная проза — `chop`.
- Обычные пользовательские упоминания `Learning Path`, `Reference` и `Level` приведены к естественным русским формам «Путь обучения», «Справочник» и «уровень».
- Локальные `Training Questions` в пользовательской прозе называются «тренировочными вопросами», без смешения с официальными контрольными вопросами.

### Исправлено

- Ссылки «Отредактировать эту страницу» на русских страницах теперь ведут в локализованные исходники `i18n/ru/...`, а не в английские `docs/...`.
- Для страницы «О русской версии» исправлен browser/meta title: теперь он локализован и не дублирует общий title сайта.
- Устранены остаточные англоязычные и смешанные названия в Beginner, Learning Path, Reference, About и материалах уровней.

### Проверено

- Выполнен финальный whole-site consistency pass по пользовательской терминологии и повторяющимся названиям.
- RU production build прошёл успешно.
- В собранном сайте проверены 217 HTML-страниц: битых внутренних targets и anchors не обнаружено.
- Проверены 211 ссылок редактирования русских страниц: все ведут в локализованные `i18n/ru/...` файлы.
- Выполнен browser visual smoke на representative страницах, включая Reference, Beginner и переведённый Official Challenge Question; layout/clipping regressions не обнаружены.

## 2026-08-16 — Training Questions audit

### Исправлено

- У Training Questions удалены видимые тематические метки после текста вопроса: вопрос больше не подсказывает проверяемую конвенцию своим названием.

## 2026-08-15 — Product V1

### Добавлено

- Структурированный локальный поиск по Справочнику с ранжированием conventions и сущностей, aliases, ссылками на конкретные места, состоянием запроса в URL и алфавитным просмотром.
- Фильтр Справочника «Только до моего уровня» для Beginner и Levels 1–25; при выключенном фильтре снова доступен полный Справочник, включая Extras.
- Опциональный поиск по Variant-Specific в отдельном блоке результатов с сохранением состояния через `variants=1`.
- Отдельный просмотр и поиск по Variant-Specific.
- Компактный поиск по Словарю основных терминов H-Group.
- Постоянно сохраняемый «Мой уровень» для Beginner и Levels 1–25.
- Навигация Learning Path с текущим и следующим canonical Level и прямыми ссылками на страницы уровней.
- Генерация продуктовых данных из локализованного MDX-корпуса вместо второго вручную поддерживаемого каталога.
- Более безопасное для полей ввода и локализованное поведение клавиатурной навигации.

### Изменено

- Главная страница упрощена вокруг основных сценариев: начать обучение, продолжить Learning Path, открыть Справочник и Словарь.
- Полезные навигационные карточки на главной странице теперь идут перед уведомлением о локализации.
- Улучшена информационная архитектура Справочника без удаления официальных объяснений из обычного потока страницы.
- Уточнён переход Beginner → Level 1 → Level 2 в Learning Path.
- Приведены к единой политике названия Variant-Specific и русские формулировки, включая контекстный перевод обычных цветов.
- Отредактированы формулировки Brown и Color Blind без изменения официальных названий conventions и вариантов.

### Исправлено

- `Tempo Clue`, `Tempo Clues` и redirect из Extras больше не отображаются как отдельные дубли в Справочнике.
- Названия Levels 1–25 в Learning Path синхронизированы с canonical titles самих страниц уровней.
