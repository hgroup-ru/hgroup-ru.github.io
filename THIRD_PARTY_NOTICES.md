# Сторонние компоненты

Этот файл фиксирует сторонние компоненты, которые H-Group RU добавляет поверх закреплённого upstream и для которых полезно явно отметить отдельные лицензионные условия. Он не заменяет лицензионные файлы самих пакетов.

## `@cspell/dict-ru_ru`

- версия: `2.3.2`;
- назначение: русский словарь для CSpell во время lint;
- лицензия пакета: `GPL-3.0-or-later`;
- upstream: `streetsidesoftware/cspell-dicts`, `dictionaries/ru_RU`;
- пакет устанавливается через npm как `devDependency`, не vendored в репозиторий и не включается в опубликованный Docusaurus site artifact.

Остальные npm-зависимости наследуются из upstream-проекта либо устанавливаются пакетным менеджером и сохраняют собственные лицензии. `node_modules/` и другие установленные копии зависимостей не коммитятся в этот репозиторий.
