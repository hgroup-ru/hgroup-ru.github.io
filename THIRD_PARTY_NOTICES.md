# Сторонние компоненты

Здесь перечислены сторонние компоненты, которые H-Group RU добавляет поверх зависимостей исходного проекта и для которых полезно отдельно указать лицензионные условия. Этот файл не заменяет лицензии самих пакетов.

## `@cspell/dict-ru_ru`

- версия: `2.3.2`;
- назначение: русский словарь для CSpell;
- лицензия: `GPL-3.0-or-later`;
- исходный проект: `streetsidesoftware/cspell-dicts`, `dictionaries/ru_RU`;
- пакет используется только как `devDependency`, устанавливается через npm и не входит в опубликованный сайт.

Остальные npm-зависимости либо унаследованы от исходного проекта, либо устанавливаются пакетным менеджером и сохраняют собственные лицензии. Каталог `node_modules/` в репозиторий не коммитится.
