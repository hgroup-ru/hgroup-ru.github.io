# Сторонние компоненты

Здесь перечислены сторонние компоненты, которые H-Group RU добавляет поверх зависимостей исходного проекта и для которых полезно отдельно указать лицензионные условия. Этот файл не заменяет лицензии самих пакетов.

## `@cspell/dict-ru_ru`

- версия: `2.3.2`;
- назначение: русский словарь для CSpell;
- лицензия: `GPL-3.0-or-later`;
- исходный проект: `streetsidesoftware/cspell-dicts`, `dictionaries/ru_RU`;
- пакет используется только как `devDependency`, устанавливается через npm и не входит в опубликованный сайт.

Остальные npm-зависимости либо унаследованы от исходного проекта, либо устанавливаются пакетным менеджером и сохраняют собственные лицензии. Каталог `node_modules/` в репозиторий не коммитится.

## `misc/rules.md`

- назначение: описание базовых правил Hanabi, унаследованное от исходного проекта;
- исходный проект указывает, что текст скопирован из официального буклета American Hanabi Deluxe;
- в самом файле сохранены ©2014 R&R Games Inc., `all rights reserved` и указание на использование с разрешения Cocktail Games и Les XII singes;
- этот файл не следует считать автоматически доступным под `CC BY-SA 4.0` только потому, что он находится в репозитории H-Group;
- русский текст базовых правил, если он понадобится, следует писать самостоятельно по механике игры, а не делать дословный перевод этого файла без отдельно подтверждённого права на адаптацию.
