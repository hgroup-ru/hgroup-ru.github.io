<TabItem value="question">

Alice 5 Pulls Donald's red 3. Bob blind-plays red 1 and Cathy then blind-plays red 2 before Donald's turn. Is this illegal merely because the 5 Pull Finesse rule says a Reverse Finesse cannot be initiated directly?

<Question />

</TabItem>
<TabItem value="solution">

**No.** This is a valid **5 Pull Double Finesse**. A basic 5 Pull Finesse must be forward, but a Double Finesse may have a Reverse Finesse component on the second blind-play. Donald's pulled red 3 connects to the final red-2 blind-play.
