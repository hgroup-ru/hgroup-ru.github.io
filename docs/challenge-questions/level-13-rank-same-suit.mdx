<TabItem value="question">

Alice clued Cathy number 3 on the first turn. Bob blind-played red 1, and Cathy's touched card happens to be red 3. Does the shared red suit promise that Bob also has red 2?

<Question />

</TabItem>
<TabItem value="solution">

**No.** The clue was number 3, and rank 1 does not connect to rank 3. This is therefore a 3 Bluff even though the physical cards share a suit. Cathy only knows that her card is a 3; Bob is not promised red 2 by this line.
