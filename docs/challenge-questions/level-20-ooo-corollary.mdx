<TabItem value="question">

Red 2 is played. Alice clues red to Cathy, touching slots 2 and 3, but Bob blind-plays an unrelated card instead of giving an Out-of-Order Fix Clue. What negative information can Cathy record about the touched red cards?

</TabItem>
<TabItem value="solution">

By the **Out-of-Order Corollary**, Cathy can mark the touched cards as **not the next playable red card**. In the source example, slot 2 becomes red 4 from the Bluff interpretation and slot 3 becomes red 5: if slot 3 were red 3, Bob would have been forced to give a Fix Clue instead of blind-playing.
