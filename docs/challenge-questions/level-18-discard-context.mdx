<TabItem value="question">

Alice discards a playable red 4, but the previous turns were extremely busy and there was no reasonable opportunity for the team to save it. Should Alice automatically write red-4 Elimination Notes on her remaining hand?

<Question />

</TabItem>
<TabItem value="solution">

**No.** Elimination depends on the surprising decision to let an important card go. If the game was genuinely too busy to save it, that surprise is absent. Players must use context and should not mechanically create Elimination Notes after every playable discard.

</TabItem>
