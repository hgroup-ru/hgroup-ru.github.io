<TabItem value="question">

In the Low Score Phase, a rank-5 clue is forced into 5 Pull logic. The card next to the 5 is not playable. If it is (a) two-or-more-away-from-playable, or (b) trash, which Finesse Position does the next player use?

</TabItem>
<TabItem value="solution">

For **(a)** the clue is a **5 Number Ejection**, so the next player uses the **Second Finesse Position**. For **(b)** it is a **5 Number Discharge**, so the next player uses the **Third Finesse Position**. One-away-from-playable would instead be a 5 Pull Finesse, while playable would be an ordinary 5 Pull.

</TabItem>
