<TabItem value="question">

Alice clues number 3 to Bob. The clue fills a previously red-clued card in as red 3 **and** newly secures another valuable 3, enough to satisfy Minimum Clue Value Principle. Bob blind-plays what he thinks is red 2, but it is a playable duplicate of Cathy's globally known blue 2. Should Bob add a Time Travel Chop Move on his own hand because his blind-play was duplicated?

<Question />

</TabItem>
<TabItem value="solution">

**No.** Blind-form Time Travel requires the clue to **fail Minimum Clue Value Principle**. Here the newly secured valuable 3 already supplies a normal duplicitous explanation, so the duplicate blind-play is a **Duplicitous Blind-Play**, not Time Travel. Bob must not manufacture an extra Chop Move.
