<TabItem value="question">

On the first turn Alice clues red to Cathy, touching red 5, red 1, red 2, and red 4. With a number-5 Fix, Cathy can play red 1 and red 2, Bob would need to blind-play only red 3, and Cathy can then continue through red 4 and red 5. Is this still a 5 Color Ejection?

<Question />

</TabItem>
<TabItem value="solution">

**No.** With only **one** required Bob blind-play, the two-or-more threshold for 5 Color Ejection is not met. Bob gives the number-5 **Fix Clue** and preserves the Out-of-Order Finesse interpretation.
