<TabItem value="question">

After Alice's Scream Discard, the next two players in a row each have a known play or known safe discard. How many Chop Moves does the Echo Scream create? Does the mechanism stop working if Alice's triggering discard was known trash?

</TabItem>
<TabItem value="solution">

It creates **three Chop Moves in total**: the echo bounces off two players. More generally, three such players in a row would create four Chop Moves, and so on. The Echo Scream rule still works the same way when the triggering Scream Discard is done with **known trash**.

</TabItem>
