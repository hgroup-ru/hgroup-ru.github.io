<TabItem value="question">

Alice has a known play but instead discards known trash, creating Shout Discard conditions. Bob already has a known play, while Cathy's chop is important. Does the Shout bounce through Bob as an Echo Shout and Chop Move Cathy too?

</TabItem>
<TabItem value="solution">

**No. Echo Shout is illegal.** Known-trash discard is not severe enough to support the Echo convention. Alice's action is interpreted as either a single Shout Discard Chop Move or a Generation Discard; it never propagates extra Chop Moves merely because Bob already has a safe action.

</TabItem>
