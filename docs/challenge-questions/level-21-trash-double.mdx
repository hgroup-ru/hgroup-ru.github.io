<TabItem value="question">

All 1s are played. Before Alice's clue, Cathy's slot 2 was already globally known trash. Alice now gives Cathy a red clue that newly touches only that off-chop card. Bob can see that the cards a Trash Chop Move would protect behind it are also trash, and the clue is not on chop, so Trash Push does not explain it.

What should Bob conclude?

<Question />

</TabItem>
<TabItem value="solution">

The clue is a **Trash Double Ignition**. The ordinary known-trash interpretations have been eliminated in this position: a Trash Chop Move would only protect bad cards, while Trash Push requires the known-trash clue to be on chop. The otherwise unexplained new known-trash clue therefore carries the Double Ignition message. If a Bad Trash Chop Move Ejection can be imagined, Level 21 still gives Trash Double Ignition priority because the bad ejection is exceptionally rare and belongs to later material.
