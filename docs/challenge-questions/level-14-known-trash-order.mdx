<TabItem value="question">

All 1s are already played. Alice has two number-1-clued cards, on slots 2 and 4, so both are equally known trash. No later-level discharge exception is active. If Alice wants an ordinary known-trash discard with no extra message, which card should she discard?

<Question />

</TabItem>
<TabItem value="solution">

**Slot 2.** When a player has multiple equally known-trash cards, the expected Known-Trash Discard Order is the **leftmost** trash card. Discarding slot 4 instead would skip the expected trash card and can therefore carry extra meaning.
