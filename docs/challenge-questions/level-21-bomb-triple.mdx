<TabItem value="question">

Alice intentionally bombs known trash, apparently starting a Bomb Double Ignition. Everyone can plainly see that Alice could instead have used an ordinary clue-based Double Ignition, such as Replay Double Ignition. What extra message does choosing the strike communicate?

</TabItem>
<TabItem value="solution">

It communicates a **Bomb Triple Ignition**. A clue is almost always preferable to spending a strike, so the team should normally choose a clue-based Double Ignition first. If Alice obviously had that option but deliberately used the Bomb form anyway, the unnecessary extra cost signals one additional Ignition: a Triple Ignition.

</TabItem>
