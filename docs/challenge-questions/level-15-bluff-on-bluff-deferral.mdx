<TabItem value="question">

Alice has given a clue that Bob may need to answer with an immediate blind-play as a Bluff. Before resolving it, Bob notices a different clue he could give that would itself Bluff Cathy. Bob can either resolve Alice's clue now or start the new Bluff first.

Which action should Bob choose?

<Question />

</TabItem>
<TabItem value="solution">

Bob should **resolve Alice's clue instead of starting another Bluff**. Deferring a possible Bluff to perform **another Bluff should almost never be done**: it fractures the game into competing hypothetical states for different clue recipients. If Alice's original clue could be a Double Bluff, the restriction is stronger still—Bob must not defer at all.
