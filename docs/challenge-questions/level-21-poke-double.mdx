<TabItem value="question">

All 1s are played. Bob already knows that his red-clued card is trash. Alice has a known safe discard, but instead she gives Bob the same red clue again and touches no new cards.

How should the team interpret the re-touch?

<Question />

</TabItem>
<TabItem value="solution">

It is a **Poke Double Ignition**. Re-cluing globally known trash is otherwise a useless action except when a player needs a Stall. Alice has a safe discard here, so the Stall explanation is absent; because no new cards are introduced, the re-touch communicates a Double Ignition. Poke Double Ignition can be used throughout the game rather than only near the end.

</TabItem>
