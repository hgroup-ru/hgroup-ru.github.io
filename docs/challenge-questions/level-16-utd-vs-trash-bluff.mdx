<TabItem value="question">

A clue focuses a card that is actually trash. From the receiver's empathy before any reaction, the card could be either trash, currently playable/delayed playable, **or a useful currently unplayable card**. Is an ordinary Trash Bluff blind-play sufficient to prove the focus is trash?

</TabItem>
<TabItem value="solution">

**No.** The useful currently-unplayable possibility makes an ordinary Trash Bluff insufficient: a normal blind-play could leave the receiver with a false useful identity. This is the distinguishing case for an **Unknown Trash Discharge**, so the next player uses the **Third Finesse Position** to prove that the focus is trash.

</TabItem>
