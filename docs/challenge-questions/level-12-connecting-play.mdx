<TabItem value="question">

Alice knows that she has both the playable red 2 and the playable blue 2. Bob visibly holds the red 3 but no blue 3. Alice has no unusually strong clue to give instead.

Which playable card should Alice prefer?

<Question />

</TabItem>
<TabItem value="solution">

Alice should **play red 2 first**, because it leads directly into Bob's red 3 and therefore empowers a teammate. Level 12 treats this as the normal teamwork preference when choosing between multiple known playable cards. If Alice instead played blue 2, teammates should not automatically interpret the unexpected order as a coded signal; special mandatory play ordering is introduced only later.
