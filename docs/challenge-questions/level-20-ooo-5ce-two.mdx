<TabItem value="question">

On the first turn Alice clues red to Cathy, touching red 5 in slot 1, red 1 in slot 2, and red 2 in slot 3. An Out-of-Order Finesse repair with a number-5 Fix would require Bob to blind-play both red 3 and red 4. Which interpretation takes precedence?

<Question />

</TabItem>
<TabItem value="solution">

**5 Color Ejection.** The 5 Color Ejection takes precedence over Out-of-Order Finesse when the competing OOO line would require **two or more blind-plays from the same player**. Bob therefore uses the Ejection interpretation instead of giving the Fix Clue.
