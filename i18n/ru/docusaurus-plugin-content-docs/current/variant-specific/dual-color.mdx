Эти конвенции применяются к вариантам с dual-color цветом.

### Унаследованные конвенции {/* #inherited-conventions */}

- По умолчанию dual-color карты наследуют все [радужные конвенции](rainbow.mdx).
- Например, можно сделать _Free Choice Finesse_, дав dual-color карте подсказку цветом.
