Эти конвенции применяются к вариантам «Totally Blind».

### Таблицы интерпретации подсказок {/* #clue-interpretation-tables */}

- Как и в конвенциях для вариантов _Color Blind_, мы задаём произвольные интерпретации для каждой подсказки.

#### 2–3 игрока {/* #2-player--3-player */}

| Подсказка  | Интерпретация                                                             |
| ---------- | ------------------------------------------------------------------------- |
| Число 1    | Сыграть слот 1                                                            |
| Число 2    | Сыграть слот 2                                                            |
| Число 3    | Сыграть слот 3                                                            |
| Число 4    | Сыграть слот 4                                                            |
| Число 5    | Сыграть слот 5                                                            |
| Красный    | _Chop Move_                                                               |
| Жёлтый     | Сыграть слот 1 + сыграть слот 2                                           |
| Зелёный    | Сыграть слот 1 + сыграть слот 3                                           |
| Синий      | Сыграть слот 1 + сыграть слот 4                                           |
| Фиолетовый | Сыграть слот 1 + сыграть слот 5                                           |
| Teal       | Двойной _Chop Move_ (или пустая по смыслу подсказка в Stalling Situation) |

#### 4–5 игроков {/* #4-player--5-player */}

| Подсказка  | Интерпретация                                                                                 |
| ---------- | --------------------------------------------------------------------------------------------- |
| Число 1    | Сыграть слот 1                                                                                |
| Число 2    | Сыграть слот 2                                                                                |
| Число 3    | Сыграть слот 3                                                                                |
| Число 4    | Сыграть слот 4                                                                                |
| Число 5    | _Chop Move_                                                                                   |
| Красный    | Двойной _Chop Move_ (или пустая по смыслу подсказка в Stalling Situation)                     |
| Жёлтый     | Сыграть слот 1 + сыграть слот 2                                                               |
| Зелёный    | Сыграть слот 1 + сыграть слот 3                                                               |
| Синий      | Сыграть слот 1 + сыграть слот 4                                                               |
| Фиолетовый | Два игрока играют _Finesse Position_ (подсказку обязательно дать игроку со вторым blind-play) |
| Teal       | Три игрока играют _Finesse Position_ (подсказку обязательно дать игроку с третьим blind-play) |

#### 6 игроков {/* #6-player */}

| Подсказка  | Интерпретация                                                                                             |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| Число 1    | Сыграть слот 1                                                                                            |
| Число 2    | Сыграть слот 2                                                                                            |
| Число 3    | Сыграть слот 3                                                                                            |
| Число 4    | _Chop Move_                                                                                               |
| Число 5    | Двойной _Chop Move_ (или пустая по смыслу подсказка в Stalling Situation)                                 |
| Красный    | Два игрока играют свои _Second Finesse Position_ (подсказку обязательно дать игроку со вторым blind-play) |
| Жёлтый     | Сыграть слот 1 + сыграть слот 2                                                                           |
| Зелёный    | Сыграть слот 1 + сыграть слот 3                                                                           |
| Синий      | Сыграть слот 1 + сыграть слот 2 + сыграть слот 3                                                          |
| Фиолетовый | Два игрока играют _Finesse Position_ (подсказку обязательно дать игроку со вторым blind-play)             |
| Teal       | Три игрока играют _Finesse Position_ (подсказку обязательно дать игроку с третьим blind-play)             |

### Продвинутые конвенции {/* #advanced-conventions */}

- В вариантах Totally Blind _Ejections_ и _Discharges_ работают заметно иначе. См. [специальные конвенции для вариантов без позитивных подсказок](no-positive-clues.mdx).
