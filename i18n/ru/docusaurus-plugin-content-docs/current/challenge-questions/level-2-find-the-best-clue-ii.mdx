- У Боба есть неизвестная карта с отметкой 5.
- У Кэти есть неизвестная жёлтая карта.
- Какую лучшую подсказку может дать Алиса?

<TabItem value="solution">

- Самая ценная подсказка Алисы — зелёная подсказка для Боба. Это _Play Clue_ на зелёную 4, которая запускает [_Reverse Finesse_](../level-2.mdx#the-reverse-finesse).
- В отличие от предыдущего вопроса, _Reverse Finesse_ сработает, потому что Кэти знает: её жёлтая карта не может быть связующей картой для зелёной 4.
- Алиса также могла бы дать Кэти подсказку числом 3 как _Play Clue_ на зелёную 3. Заодно эта подсказка «уточнит» жёлтую 3. Но она «получит» только одну совершенно новую карту вместо двух.
