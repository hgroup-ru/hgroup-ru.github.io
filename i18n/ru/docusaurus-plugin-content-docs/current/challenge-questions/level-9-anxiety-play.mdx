<TabItem value="question">

У Боба Locked Hand, и он начинает ход при 0 подсказок. Команда намеренно оставила его при 0, вместо того чтобы потратить подсказку и повторно подсказать одну из его карт. Судя по заметкам Боба, две его карты одинаково правдоподобно могут быть играбельными.

Какую карту должен сыграть Боб?

<Question />

</TabItem>
<TabItem value="solution">

Боб должен сделать **Anxiety Play** и сыграть **самую левую из двух одинаково правдоподобных карт**. Если Locked-игрока намеренно оставили при 0 подсказок, это сообщает ему, что одна из его карт на самом деле играбельна. Сначала он выбирает наиболее вероятную играбельную карту; при равенстве Leftmost Playable Principle выбирает самую левую.

</TabItem>
