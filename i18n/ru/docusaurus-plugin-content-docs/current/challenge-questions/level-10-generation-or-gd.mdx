<TabItem value="question">

Красная стопка дошла до 3, доступно 0 подсказок. У Алисы есть две красные карты с подсказками, которые она уже точно определила как `r4` и `r5`. В Finesse Position Боба лежит вторая `r4`; его `b2` находится на chop, а старая `b5` уже имеет подсказку. У Кэти на chop лежит `y5`.

Если Алиса просто сыграет свою `r4`, Бобу придётся сбросить `b2`, чтобы создать жетон для спасения `y5`. Алиса также могла бы сама сбросить неизвестную chop-карту как Generation Discard.

Есть ли здесь более сильная линия 10-го уровня?

<Question />

</TabItem>
<TabItem value="solution">

Да. Алисе следует сбросить известную `r4` как Gentleman's Discard.

1. Алиса сбрасывает `r4` и создаёт один жетон подсказки.
2. Боб играет переданную `r4`; красная стопка доходит до 4.
3. Кэти даёт Бобу синюю Play Clue: фокусом становится ранее незатронутая `b2`, а старая `b5` только получает дополнительную информацию.
4. Известная Алисе `r5` теперь играбельна. Алиса играет её и возвращает жетон подсказки за розыгрыш 5.
5. Боб тратит этот жетон на 5 Save по `y5` Кэти до её хода.

По сравнению с Generation Discard эта линия не рискует неизвестной chop-картой, продвигает красную стопку, сохраняет `b2` и всё равно создаёт жетон, необходимый для спасения `y5`.
