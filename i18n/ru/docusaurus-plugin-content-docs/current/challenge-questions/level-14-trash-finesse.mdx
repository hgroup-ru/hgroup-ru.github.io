<TabItem value="question">

Подсказка Trash Finesse впервые затрагивает **две** карты, которые получатель иначе прочитал бы как две обещанные играбельные карты. Кэти уже видит одну подходящую играбельную связку на Finesse Position другого игрока. Обещана ли вторая связка для второй затронутой карты?

</TabItem>
<TabItem value="solution">

**Нет.** Double Trash Finesse явно запрещён. Trash Finesse обещает только один подходящий blind-play, необходимый для демонстрации обмана. После него **все впервые затронутые карты** этой подсказки считаются trash. Вторая затронутая карта не требует второй связки.

</TabItem>
