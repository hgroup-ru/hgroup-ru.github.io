<TabItem value="question">

Ничего не сыграно. Алиса даёт Дональду подсказку по 4. Боб вслепую играет красную 1, а Кэти сразу вслепую играет красную 2. Физически карта Дональда — красная 4. Обещана ли теперь кому-то красная 3 только потому, что оба blind-play одного цвета с 4?

</TabItem>
<TabItem value="solution">

**Нет.** Два немедленных blind-play обозначают Hard Double Bluff. Хотя красная 1 и красная 2 физически одного цвета с красной 4, команда не выдумывает связку красной 3. Дональд знает лишь, что его карта может быть 4; совпадение цвета не превращает Double Bluff в трёхкарточную цепочку Finesse.

</TabItem>
