<TabItem value="question">

Алиса даёт Бобу Play Clue. Эта же подсказка создаёт для Боба Self-Finesse, и вместо немедленного розыгрыша подсказанной карты он сбрасывает безопасный chop. Кэти видит играбельную карту в своей Finesse Position, которая могла бы соединяться с одним из возможных значений подсказанной карты Боба.

Можно ли Кэти считать паузу Боба доказательством того, что ей следует вслепую сыграть свою Finesse Position?

</TabItem>
<TabItem value="solution">

**Нет.** На паузу нельзя безопасно реагировать, когда эта же подсказка создаёт для получателя **Self-Finesse**. Боб может ждать из-за собственной скрытой связи, а играбельная Finesse Position Кэти не обязана совпадать с подсказанной картой. Поэтому пауза не даёт Кэти однозначного основания для blind-play из Finesse Position.

</TabItem>
