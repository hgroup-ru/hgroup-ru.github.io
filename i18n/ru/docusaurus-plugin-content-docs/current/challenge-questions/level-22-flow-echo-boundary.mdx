Алиса делает экстренный сброс. У Боба уже есть известная играбельная красная 2. У Кэти нет известной игры или безопасного сброса, но её chop — обычная некритическая карта: это не уникальная играбельная карта, не критическая карта и не уникальная 2.

Должен ли Боб насильно относить эту позицию к стандартной ветке Echo Scream или Generation из flowchart уровня 22?

<Question />

</TabItem>
<TabItem value="solution">

**Нет.** Именно на этой ветке flowchart уровня 22 намеренно заканчивается. Алиса либо сделала продвинутый ход, который схема не классифицирует, либо просто ошиблась. Поскольку Scream и Generation Discard должны быть ходами последней надежды, Бобу нужно рассуждать по реальным картам, которые требуется спасать, и по безопасности chop, а не придумывать стандартную метку Echo или Generation.
