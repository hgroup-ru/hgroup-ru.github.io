<TabItem value="question">

Красная стопка уже на 3. Алиса даёт Кэти красную подсказку, впервые затрагивая неподсказанную красную 5. Боб видит, что для обычного Finesse ему пришлось бы вслепую сыграть только одну карту — красную 4. Из какой позиции Боб должен играть?

<Question />

</TabItem>
<TabItem value="solution">

Боб должен вслепую сыграть из **Finesse Position**, а не из Second Finesse Position. 5 Color Ejection заменяет Finesse только когда следующему игроку понадобилось бы **два или больше слепых розыгрыша**. Один слепой розыгрыш остаётся обычным Finesse.

</TabItem>
