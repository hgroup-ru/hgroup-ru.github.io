<TabItem value="question">

В банке 0 подсказок. У Боба и Дональда критические карты на chop; у Кэти есть безопасный сброс. У Алисы и Боба есть по одной известной играбельной карте. Алиса видит, что если сыграет, Боб будет вынужден сделать Generation Discard и потерять критический chop. Что должна сделать Алиса и почему Боб с Кэти по-разному трактуют одно действие?

</TabItem>
<TabItem value="solution">

Алиса должна **сбросить**. Один и тот же сброс одновременно является **Scream Discard для Боба**, поэтому Боб делает Chop Move критической карте, и **Generation Discard для Кэти**, поэтому Кэти **не** делает Chop Move. Это **Composition Discard**: один сброс объединяет два разных экстренных значения для двух игроков.
