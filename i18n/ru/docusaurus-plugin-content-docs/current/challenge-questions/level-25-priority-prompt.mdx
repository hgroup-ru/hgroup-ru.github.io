<TabItem value="question">

Алиса намеренно играет полностью известную карту с меньшим Priority, создавая Priority-сигнал. У Боба две карты с подсказками, каждая из которых может быть следующей связкой. Какую он играет первой и что делает, если она оказывается не той связкой?

</TabItem>
<TabItem value="solution">

Боб сначала играет **самую левую подходящую карту с подсказкой** как Priority Prompt. Как и при обычном Prompt, если карта оказывается не связкой, он продолжает по подсказанным кандидатам, пока не найдёт соединяющую карту. Если у Боба вообще нет подходящей подсказанной связки, сигнал может вместо этого быть Priority Finesse на подходящей Finesse Position.

</TabItem>
