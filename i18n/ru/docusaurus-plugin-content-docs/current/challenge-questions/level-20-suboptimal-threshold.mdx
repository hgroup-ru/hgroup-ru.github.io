<TabItem value="question">

Одна синяя 3 уже сброшена, поэтому синяя 3 Боба на chop критическая. Алиса может спасти её либо синей подсказкой, либо числом 3. Подсказка числом 3 также повторно затронет известную красную 3 Боба, которая дублирует известную всей команде красную 3 Алисы. Алиса выбирает синий цвет и затрагивает только критическую синюю 3. Должен ли Боб трактовать этот выбор как Suboptimal Prompt, Finesse или Bluff?

<Question />

</TabItem>
<TabItem value="solution">

**Нет.** У синей подсказки есть обычное объяснение через **Good Touch Principle**: она не затрагивает повторно известный дубликат красной 3. Suboptimal-ход должен быть **явно и существенно хуже** доступной альтернативы без обычного объяснения. Одной только небольшой потери эффективности подсказки недостаточно, чтобы приписывать ей дополнительный смысл Play Clue.

</TabItem>
