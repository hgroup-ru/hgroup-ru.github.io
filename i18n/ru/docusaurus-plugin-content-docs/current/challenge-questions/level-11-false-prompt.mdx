<TabItem value="question">

Красная 1 и синяя 1 сыграны. У Боба есть карта, подсказанная только как 2. Алиса даёт Дональду красную Play Clue по его красной 3. Боб не видит красную 2 в других руках, поэтому его неизвестная 2 выглядит Prompted как красная 2. На самом деле карта Боба — синяя 2.

Может ли Алиса намеренно использовать этот ложный Prompt как Bluff?

<Question />

</TabItem>
<TabItem value="solution">

**Нет. Bluff Prompts / Prompt Bluffs запрещены.** Prompt обязан быть правдивым. Если Боб сыграет синюю 2, успешный розыгрыш не сообщит остальной команде немедленно, что красная связка Алисы была ложной: следующий игрок всё ещё может вывести отсутствующую красную 2 и случайно взорвать карту. Поэтому дезинформация нарушает и Lie Principle, и требование правдивости Prompt.

</TabItem>
