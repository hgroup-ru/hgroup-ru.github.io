<TabItem value="question">

У Алисы есть известная играбельная синяя 2, но вместо неё Алиса сбрасывает другую карту, известную всей команде как мусор. У следующего игрока, Боба, уже есть известная играбельная красная 2. Кто-то предлагает, чтобы из-за этого сброс отскочил через Боба как Echo Shout.

Возможно ли это?

<Question />

</TabItem>
<TabItem value="solution">

**Нет.** Shout Discard никогда не создаёт Echo Chop Move. Сброс известного мусора недостаточно рискован, чтобы нести дополнительный смысл отскока, который возможен у Scream Discard неизвестной картой. Действие Алисы должно быть либо **одиночным Shout Discard Chop Move**, либо **Generation Discard** — в зависимости от остальной позиции; безопасное действие Боба не превращает его в Echo Shout.

</TabItem>
