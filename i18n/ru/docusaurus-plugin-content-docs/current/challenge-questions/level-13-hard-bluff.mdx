<TabItem value="question">

Сыграны красная 1 и синяя 2. У Кэти есть 3 с подсказкой по числу и без информации о цвете. Алиса подсказывает Кэти новую 4, затем Боб вслепую играет красную 2. Обязана ли Кэти сразу сыграть 3 как красную 3?

<Question />

</TabItem>
<TabItem value="solution">

**Нет.** Простой Bluff всё ещё возможен, потому что синяя 4 находится в одном шаге от играбельности. Одновременно возможен красный Finesse + Prompt, если карты Кэти — красная 3 и красная 4. По Occam's Razor более простая трактовка Bluff остаётся живой: Кэти сохраняет оба варианта и не играет 3 сразу. Такая неоднозначность и называется **Hard Bluff**.
