<TabItem value="question">

Алиса делает странный Gentleman's Discard в позиции без экстренной ситуации. Совпадающая карта находится не в Finesse Position Кэти, но Боб — следующий игрок — не может безопасно вслепую сыграть соответствующую Finesse Position. Дональд, который ходит позже Кэти, смог бы чисто показать эту позицию.

Может ли Алиса задумать Blaze Discard, в котором нужный blind-play позже выполнит Дональд?

</TabItem>
<TabItem value="solution">

**Нет.** Blaze Discard должен быть показан **самым следующим игроком**. Именно Боб обязан немедленно отреагировать и тем самым указать Finesse Position совпадающей карты. Более поздний игрок не может спасти нечитаемую линию Blaze; если Боб не может выполнить нужный немедленный розыгрыш, Алиса не может рассчитывать на Дональда.

</TabItem>
</Tabs>
