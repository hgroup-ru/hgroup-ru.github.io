Боб играет **Second Finesse Position** как **5 Number Ejection**. Соседняя красная 3 слишком далека для Pull Finesse, но не является мусором. После Ejection команда знает, что слот 2 Кэти **Chop Moved** и **two-or-more-away-from-playable**.
