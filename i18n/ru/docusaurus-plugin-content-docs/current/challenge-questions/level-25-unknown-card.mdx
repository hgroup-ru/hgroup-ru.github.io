<TabItem value="question">

Алиса может сыграть полностью известную красную 2 или играбельную 2 с подсказкой по рангу, чей цвет всё ещё глобально неизвестен. Она выбирает неизвестную 2. Должен ли Боб автоматически вывести Priority Finesse из порядка игры?

</TabItem>
<TabItem value="solution">

**Нет.** Игра глобально неизвестной карты почти никогда сама по себе не запускает Priority: неизвестную карту можно выбрать ради получения информации. Обычно Priority является сигналом при осознанном выборе между **полностью известными** identity. Исключение — Trust Finesse, когда выбор неизвестной карты настолько экстремально плох без дополнительного смысла, что обычное получение информации его не объясняет.

</TabItem>
