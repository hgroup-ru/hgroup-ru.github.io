<TabItem value="solution">

Это **Bluff**. Синяя 3 Боба не соединяется с красной подсказкой, поэтому по Cathy's Connecting Principle обычная интерпретация через Finesse отпадает. Значит, цель подсказки должна быть красной картой, которая в момент подсказки была one-away-from-playable: красной 4. Кэти теперь может записать **r4** на затронутой карте.
