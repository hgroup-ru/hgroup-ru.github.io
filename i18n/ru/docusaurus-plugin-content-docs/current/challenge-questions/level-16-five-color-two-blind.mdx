<TabItem value="question">

Красная стопка на 2. Алиса даёт Кэти красную подсказку, впервые затрагивая неподсказанную красную 5. Боб видит красную 3 и красную 4 как две карты, которые пришлось бы вслепую сыграть для обычного Finesse. Из какой позиции он должен сыграть вместо этого?

<Question />

</TabItem>
<TabItem value="solution">

Боб должен вслепую сыграть из **Second Finesse Position**. Поскольку обычный Finesse потребовал бы двух слепых розыгрышей, подсказка читается как **5 Color Ejection**. Prompt не учитываются в этом пороге — считаются только blind-plays.

</TabItem>
