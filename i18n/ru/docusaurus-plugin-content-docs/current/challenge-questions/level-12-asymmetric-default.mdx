<TabItem value="question">

Боб делает ход, который можно было бы объяснить тем, что он самостоятельно вывел точное значение одной из своих карт. Кэти не может восстановить такой вывод из доступной ей информации, но у хода Боба есть и обычное объяснение по conventions, не требующее асимметричного знания.

Следует ли Кэти считать, что у Боба есть асимметричная информация?

</TabItem>
<TabItem value="solution">

**Нет.** На 12-м уровне по умолчанию не следует предполагать, что другой игрок располагает асимметричной информацией. Такое знание — исключение. Пока существует обычное объяснение по conventions, Кэти должна использовать его; особое личное знание Боба следует выводить только тогда, когда другого разумного объяснения его ходу не остаётся.

</TabItem>
</Tabs>
