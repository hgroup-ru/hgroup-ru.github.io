<TabItem value="question">

У Алисы стоят Elimination Notes для красной 2 на слотах 2–5. Боб даёт подсказку числом 3 на слоты 2, 3 и 4. Негативная информация снимает с этих карт Notes для красной 2, оставляя слот 5 как единственный вариант красной 2. Делает ли это новое знание о карте на chop слот 4 задним числом фокусом подсказки Боба числом 3?

<Question />

</TabItem>
<TabItem value="solution">

**Нет.** Фокус с учётом chop определяется **до выдачи подсказки**. В этот момент подсказка обычно фокусируется на самой новой затронутой карте — слоте 2. То, что негативная информация затем однозначно определяет красную 2 в слоте 5, не переносит фокус подсказки задним числом на слот 4.
