<TabItem value="question">

Алиса даёт Бобу подсказку числом 3. Подсказка дополняет ранее красную карту до красной 3 **и** впервые сохраняет ещё одну ценную 3, чего достаточно для Minimum Clue Value Principle. Боб вслепую играет карту, которую считает красной 2, но там играбельный дубликат известной всей команде синей 2 Кэти. Должен ли Боб добавить Time Travel Chop Move на собственной руке из-за дублированного blind-play?

<Question />

</TabItem>
<TabItem value="solution">

**Нет.** Time Travel Chop Move (Blind-Play Form) требует, чтобы подсказка **не удовлетворяла Minimum Clue Value Principle**. Здесь впервые сохранённая ценная 3 уже даёт обычное объяснение через дублирование, поэтому дублированный blind-play — это **Duplicitous Blind-Play**, а не Time Travel. Боб не должен создавать дополнительный Chop Move.

</TabItem>
