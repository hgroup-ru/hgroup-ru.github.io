<TabItem value="question">

Алиса делает Blaze Discard известной красной 3, хотя никакой экстренной ситуации нет. Боб видит вторую красную 3 в полностью неподсказанной руке Кэти: она лежит на слоте 2, то есть в её Second Finesse Position. У Боба на слоте 1 лежит подсказанная 5, поэтому его Finesse Position находится на слоте 2, а Second Finesse Position — на слоте 3.

Какой слот Боб должен сыграть вслепую, чтобы правильно обозначить положение красной 3 Кэти?

</TabItem>
<TabItem value="solution">

Боб должен вслепую сыграть **слот 3**, свою **Second Finesse Position**. Blaze Discard копирует **номер Finesse Position** совпадающей карты, а не её физический номер слота. Красная 3 Кэти находится в её Second Finesse Position, поэтому Боб демонстрирует свою Second Finesse Position, которая у него приходится на слот 3.

</TabItem>
