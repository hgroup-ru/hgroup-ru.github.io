<TabItem value="question">

При 0 подсказок Алиса сбрасывает вместо игры, потому что chop Боба нужно защитить, **и одновременно** Кэти нужна сгенерированная подсказка для спасения более позднего критического chop. Как один сброс может дать Бобу и Кэти разные инструкции?

</TabItem>
<TabItem value="solution">

Это может быть **Composition Discard**: Scream Discard в сторону Боба, поэтому Боб делает Chop Move и не имеет права сбрасывать этот chop, и одновременно Generation Discard в сторону Кэти, поэтому Кэти не Chop Moved и получает пользу от сгенерированной подсказки. Родственная авария позже может вызвать Rebellious Discard: игрок после Scream обычно не может сбрасывать, но если трата подсказки оставит следующую Locked-критическую руку при 0 подсказок, он делает обычный Chop Move, а затем сбрасывает новый chop, чтобы снова сгенерировать подсказку.

</TabItem>
