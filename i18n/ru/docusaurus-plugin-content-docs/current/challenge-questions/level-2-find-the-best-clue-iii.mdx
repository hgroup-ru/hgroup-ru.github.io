<TabItem value="question">

- У Боба есть неизвестная карта с отметкой 5.
- У Кэти есть неизвестная фиолетовая карта.
- Какую лучшую подсказку может дать Алиса?

<RuOfficial10Q />

</TabItem>
<TabItem value="solution">

- Самая ценная подсказка Алисы — подсказка числом 4 для Боба. Это _Play Clue_ на красную 4, которая запускает [_Self-Finesse_](../level-2.mdx#the-self-finesse).
- Алиса может ожидать, что Боб войдёт в _Self-Finesse_, потому что:
  - Боб знает, что подсказка числом 4 не может быть _Save Clue_: сейчас ни одна 4 не является критической.
  - Боб знает, что подсказка числом 4 не может быть прямой _Play Clue_, поскольку сейчас нет ни одной немедленно играбельной 4.
  - Боб знает, что подсказка числом 4 не может быть [_Reverse Finesse_](../level-2.mdx#the-reverse-finesse), потому что в _Finesse Position_ Кэти нет играбельной карты, которая могла бы связаться с 4.
- Алиса также могла бы дать Бобу подсказку числом 3 как _Play Clue_ на красную 3, но такая подсказка «получит» только одну совершенно новую карту вместо двух.
