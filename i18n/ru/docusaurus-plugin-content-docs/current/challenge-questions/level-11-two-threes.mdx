<TabItem value="question">

Все 1 уже были сыграны. У Кэти уже есть две разные карты с подсказками по числу 3. Затем Алиса дала Дональду красную Play Clue по его красной 4.

**Подсказка Алисы:**

<Clue />

Боб сразу вслепую сыграл свою Finesse Position вместо ожидаемой красной 2. Там оказалась синяя 2, которая успешно сыгралась, поэтому подсказка раскрылась как Bluff.

**После хода Боба:**

<After />

Что именно Кэти может заключить о своих двух 3 с подсказками?

</TabItem>
<TabItem value="solution">

Кэти обещано, что **одна из подходящих 3 с подсказками является красной 3**, но **конкретный слот ей не обещан**. Bluff может проходить через уже подсказанную связующую карту и устанавливать её значение, однако при нескольких подходящих картах позиция остаётся неоднозначной. Кэти должна сохранять оба варианта слота, пока дальнейшая информация их не различит.

Удобно записать **r3?** на обеих кандидатных картах: общий для двух слотов факт состоит в том, что ровно одна из них — красная 3.
