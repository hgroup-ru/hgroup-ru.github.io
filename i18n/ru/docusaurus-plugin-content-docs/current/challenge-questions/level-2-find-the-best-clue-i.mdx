<TabItem value="question">

- У Боба есть неизвестная синяя карта.
- У Кэти есть неизвестная карта с отметкой 2.
- Какую лучшую подсказку может дать Алиса?

<RuOfficial8Q />

</TabItem>
<TabItem value="solution">

- У Алисы есть только одна допустимая подсказка: подсказка числом 2 для Кэти.
- Алиса не может дать подсказку на красную 3 — ни по цвету, ни по числу — чтобы начать [_Reverse Finesse_](../level-2.mdx#the-reverse-finesse), потому что Кэти затем сыграла бы неизвестную карту с отметкой 2 как красную 2, предполагая _Prompt_, а не _Finesse_.
- Алисе также следует избегать красной подсказки для Кэти: она нарушила бы [_Good Touch Principle_](../beginner/good-touch-principle.mdx), затронув мусорную красную 1.
