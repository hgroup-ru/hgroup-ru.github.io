<TabItem value="question">

Алиса даёт Кэти красную подсказку, которая выглядит как дублирование красной 2, уже видимой в руке Дональда. Обычные исключения для допустимого дублирования не действуют. Может ли Боб считать это Unknown Dupe Discharge просто потому, что дубликат существует где-то за столом?

<Question />

</TabItem>
<TabItem value="solution">

**Нет.** Unknown Dupe Discharge применяется только когда две дублированные карты находятся **в руке одного и того же игрока**. Дублирование карты в чужой руке нельзя использовать для запуска UDD; у подсказки должно быть другое значение.

</TabItem>
