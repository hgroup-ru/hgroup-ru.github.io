title: "Контрольные вопросы"

Контрольные вопросы помогают проверить понимание конвенций перед тем, как применять их в реальной партии. Они полезны для разбора конкретных решений, но не заменяют полноценную практику с реальными людьми.

## Официальные контрольные вопросы

В русской локализации переведены официальные наборы для **уровней 2–8** — весь набор Official Challenge Questions, присутствующий в текущем upstream.

## Локальные контрольные вопросы H-Group RU

Для уровней, где отдельного официального набора нет, H-Group RU может готовить собственные контрольные вопросы. Они проверяются по материалу соответствующего уровня, но **не являются Official Challenge Questions H-Group**.

Сейчас доступен локальный набор для [уровня 10](./challenge-questions/level-10.mdx). По мере подготовки следующих уровней их наборы будут добавляться сюда же.
