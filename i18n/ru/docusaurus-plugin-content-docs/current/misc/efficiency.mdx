# Таблицы Pace и Efficiency

## Pace

- **Pace** показывает, сколько сбросов команда ещё может сделать до момента, когда максимальный счёт станет невозможен.
- Формула Pace:
  - `всего карт в колоде - ((размер руки игрока - 1) * число игроков) - (5 * число мастей)`
  - Если в партии есть detrimental character _Contrarian_, из Pace дополнительно вычитается `(число игроков - 2)`.

## Efficiency

- **Efficiency** показывает, сколько полезного результата команда получает на уже потраченные подсказки.
- Формула Efficiency:
  - `(число сыгранных карт + число карт, на которых есть хотя бы одна подсказка) / число выданных или потерянных подсказок`
  - Формула предполагает использование _Good Touch Principle_.

- Минимальная Efficiency определяется как:
  - `общее число карт, которые нужно сыграть / максимальное число подсказок, которые можно выдать до конца игры`
- Формула минимальной Efficiency:
  - `(5 * число мастей) / (8 + floor((начальный Pace + число мастей - unusable clues) / discards per clue))`
  - `unusable clues` по умолчанию равно 1, но в игре на 5/6 игроков — 2;
  - в _Throw It in a Hole_ `unusable clues` равно числу мастей;
  - если в игре есть detrimental character _Contrarian_, `unusable clues` всегда равно 1;
  - `discards per clue` по умолчанию равно 1, а в _Clue Starved_ — 2.
- Для подсчёта общего числа выданных или потерянных подсказок учитываются:
  - +8 за восемь стартовых подсказок;
  - начальный Pace, потому что каждый сброс возвращает одну подсказку;
  - число мастей, потому что сыгранная 5 каждой масти возвращает подсказку;
  - `unusable clues`, потому что подсказку, полученную за последнюю сыгранную 5, уже нельзя использовать;
  - в игре на 5/6 игроков `unusable clues` равно 2, потому что в финальном круге невозможно сыграть 6 или 7 карт одной масти.
