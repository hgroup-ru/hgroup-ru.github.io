- Поздравляем: руководство для начинающих пройдено. Теперь вы знаете базовый способ игры H-Group:
  1. как сбрасывать — **chop**;
  2. два типа подсказок — **Play Clues** и **Save Clues**;
  3. как интерпретировать подсказку — **Single-Card Focus**;
  4. не дублировать карты — **Good Touch Principle**;
  5. спасать все важные карты — **Save Principle**;
  6. играть эффективно — **Minimum Clue Value Principle**;
  7. «погасить» все доступные подсказки в **Early Game**;
  8. по возможности использовать **Prompts** и **Finesses**.
- После этого вы готовы сыграть несколько партий с другими участниками H-Group.
- Официальное руководство для начинающих отдельно рекомендует **не читать остальные продвинутые материалы сайта, пока вы не сыграли достаточно партий с группой**. Сначала базовые договорённости должны стать привычными на практике.
- Следующий практический шаг в оригинале — узнать, [как присоединиться к игре H-Group](/how-to-join).

> **Примечание русской версии:** после нескольких игр можно вернуться к этой локализации и перейти к **Пути обучения** и **Справочнику**.
