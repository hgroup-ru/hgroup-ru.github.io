- Hanabi — игра на эффективность, потому что количество жетонов подсказок ограничено.
- Поэтому идеальный результат — получить **два и более розыгрыша** из **одной подсказки**.
- Для этого используются два специальных приёма: **Prompts** и **Finesses**.
- Дальше разберём их по отдельности.
