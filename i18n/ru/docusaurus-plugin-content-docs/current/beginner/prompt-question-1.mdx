- У Боба в руке две неизвестные 2, которые раньше получили подсказки.
- У Кэти в руке неизвестные 5 и 4, которые тоже раньше получили подсказки.
- Алиса даёт Кэти красную подсказку.
- Как Боб интерпретирует эту подсказку?

<RuBgqPromptQuestion1Q />

<TabItem value="solution">

- Поскольку красная 3 уже в сбросе, это **Critical Save** красной 3, то есть Save Clue.
- Поэтому Боб никак не должен реагировать.
- Если бы красной 3 не было в сбросе, подсказка была бы **Prompt** на крайнюю слева 2 Боба.
